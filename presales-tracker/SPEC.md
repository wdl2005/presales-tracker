# 售前商机跟踪 - 产品规格文档

## 1. 项目概述

- **项目名称**: 售前商机跟踪
- **项目类型**: 渐进式网页应用 (PWA)，支持安卓和苹果手机
- **核心功能**: 录入和管理售前商机交流信息，支持导出Excel
- **目标用户**: 售前工程师、销售人员

## 2. 功能模块

### 2.1 客户信息管理
- 客户名称列表（支持新增、选择）
- 数据存储在本地 LocalStorage

### 2.2 商机信息管理
- 商机名称列表（关联客户，支持新增、选择）
- 商机状态（待跟进、跟进中、已成交、已失效）
- 根据客户名称自动过滤商机列表

### 2.3 交流记录录入
- **交流地点**: 默认客户所在城市，可修改
- **客户名称**: 选择已有或新增
- **商机名称**: 选择已有（按客户过滤）或新增
- **商机状态**: 选择已有状态或新增
- **销售姓名**: 手动录入
- **是否有产品/研发支持**: 是/否 开关
- **产品/研发支持人员**: 条件显示，手动录入
- **主讲人**: 默认"我的姓名"（本地保存设置）
- **交流总结**:
  - 交流背景（文本区）
  - 交流总结（文本区）
  - 交流效果（文本区）

### 2.4 导出功能
- 导出为 Excel 格式 (.xlsx)
- 包含所有录入字段

### 2.5 设置
- 保存默认主讲人姓名
- 管理客户信息表
- 管理商机信息表

## 3. 技术方案

- **框架**: 纯 HTML/CSS/JavaScript (PWA)
- **数据存储**: LocalStorage
- **Excel导出**: SheetJS (xlsx) 库
- **UI**: 响应式设计，移动端优先

## 4. 数据结构

### 客户信息表
```json
{
  "id": "uuid",
  "name": "客户名称",
  "city": "所在城市"
}
```

### 商机信息表
```json
{
  "id": "uuid",
  "name": "商机名称",
  "customerId": "客户ID",
  "status": "商机状态"
}
```

### 交流记录
```json
{
  "id": "uuid",
  "customerId": "客户ID",
  "customerName": "客户名称",
  "opportunityId": "商机ID",
  "opportunityName": "商机名称",
  "location": "交流地点",
  "status": "商机状态",
  "salesName": "销售姓名",
  "hasSupport": true/false,
  "supportNames": "支持人员姓名",
  "presenter": "主讲人",
  "background": "交流背景",
  "summary": "交流总结",
  "result": "交流效果",
  "createTime": "创建时间"
}
```
